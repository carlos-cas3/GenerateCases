# Bitácora de sondeos — P5 (contexto / tope de tokens)

> Sondeos parciales con `PIPELINE_STOP_AFTER_STAGE=p5`. Una fila por sondeo.
> Ver [`../guia_calibracion.md`](../guia_calibracion.md) §5, Etapa 4.

**Criterio de aceptación:** sin `UNIT_EXCEEDS_TOKEN_LIMIT` (o conocido y aceptado); nº de
unidades razonable. Comparar el estimado de P5 con los tokens reales de P6 (`llm_runs`) en una
corrida completa para validar la heurística (advertencia #8).

**Parámetros:** `P5_MAX_TOKENS_PER_UNIT` (default 8000), `P5_INCLUDE_PREREQUISITES`,
`P5_INSTRUCTIONS_VERSION`.
