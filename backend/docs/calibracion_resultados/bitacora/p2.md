# Bitácora de sondeos — P2 (extracción de RF)

> Sondeos parciales con `PIPELINE_STOP_AFTER_STAGE=p2`. Una fila por sondeo.
> Ver [`../guia_calibracion.md`](../guia_calibracion.md) §5, Etapa 2.

**Criterio de aceptación:** `summary.requirements_count` > 0 y coherente con el nº de HU; sin
JSON truncado/malformado; RF atómicos y con `source_text` (spot-check).

**Parámetros:** `P2_MAX_STORIES_PER_CALL`, `P2_MAX_RETRIES`, `P2_PROMPT_VERSION`. Si hay JSON
truncado, revisar `LLM_NUM_CTX`/`LLM_THINK` (causa más frecuente).
